          08 / understand the loop

          Runbook / How it works

          A concise view of the lifecycle that this local dashboard actually exercises.

          01

          Compose

          The selected mode becomes a structured goal. Deterministic scenarios remain available regardless of provider configuration.

          02

          Plan & gate

          The core creates an allowlisted plan. Sensitive fixture actions pause at awaiting approval until you approve the real step.

          03

          Act & recover

          Bounded tools execute locally. The recovery scenario demonstrates a failed first attempt followed by a deterministic retry.

          04

          Verify & close

          The verifier inspects actual action output. Completion, partial completion, failure, timeout, and cancellation remain visible in task history.

          Current limitations

          Controlled and honest by design.

          No authentication, desktop automation, unrestricted shell/filesystem access, or production deployment is included. Gemini is used only after backend verification; the workspace report mode appears only when the API explicitly exposes an approved ARRAX_WORKSPACE_ROOT.
